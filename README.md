# 🚀 Sorting Visualizer

An interactive web-based Sorting Visualizer that demonstrates how different sorting algorithms work through animated bars. The project helps users understand algorithm execution, time complexity, and sorting behavior in real time.

## ✨ Features

- Interactive visualization of sorting algorithms
- Bubble Sort
- Quick Sort
- Merge Sort
- Adjustable animation speed
- Random array generation
- Real-time comparison & swap counter
- Time Complexity display
- Modern 3D UI with Glassmorphism effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

```bash

```

2. Open `index.html` in your browser.

No installation required.

## 📚 Algorithms Included

| Algorithm | Best | Average | Worst |
|-----------|------|----------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
